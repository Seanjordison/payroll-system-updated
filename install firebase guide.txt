Install the Firebase CLI: 
The Firebase Command Line Interface (CLI) is 
essential for developing, deploying, 
and managing Firebase projects, 
including Cloud Functions. 
Install it globally using npm:
npm install -g firebase-tools

Log in to Firebase: After installing the CLI, log in to your Firebase account from the terminal:
firebase login

Initialize your Firebase project: Navigate to your project directory in the terminal and initialize Firebase within it. This step sets up the necessary configuration files for your Firebase project and allows you to select the features you want to use, including Cloud Functions.
    firebase init
